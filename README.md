# RescuePet

## Sistema de Gestión de Rescate y Adopción Animal

### Descripción del proyecto
RescuePet es un sistema diseñado para organizar los procesos de rescate, atención veterinaria y adopción de animales. Permite registrar casos, clasificar especies, asignar responsables y realizar el seguimiento del estado de cada animal.

### Objetivo
Diseñar un sistema que facilite la gestión de rescates y adopciones mediante el registro organizado de animales y la coordinación entre administradores, voluntarios, veterinarios y ciudadanos.

### Actores principales
- **Administrador:** gestiona los casos y organiza las actividades del refugio.
- **Veterinario:** registra tratamientos y consulta el historial de los animales.
- **Voluntario:** participa en las actividades de rescate y seguimiento.
- **Ciudadano o reportante:** informa sobre animales que necesitan ayuda y consulta los animales disponibles para adopción.
